# Tangsahur Clicker

A faithful **Cookie Clicker**-inspired idle/incremental web game featuring **Tung Tung Tung Sahur** (`S-A-H-U-R`).

🎮 **Play in your browser:** https://douglaspearson2828-alt.github.io/tangsahur-clicker/

## Features
- **Classic Cookie Clicker Gameplay**: Click the Big Tangsahur, unlock 16 buildings (`Kentongan Stick` through `Sahurverse Engine`), buy 130+ upgrades, and watch your Tangsahurs per second (`TpS`) soar.
- **Golden Tangsahurs**: Catch shimmering Golden Tangsahurs for **Frenzy (×7 TpS)**, **Click Frenzy (×777 click power)**, **Lucky!**, **Building Special**, and **Sahur Storm**.
- **Milk & 100+ Achievements**: Unlock achievements to raise and flavor the Milk waves at the bottom of the drum stage, boosting Kitten multipliers.
- **Sahur Lumps & Building Levels**: Harvest maturing Sahur Lumps to level up buildings for permanent `+1%` TpS per level.
- **Ascension & Astral Skill Tree**: Ascend via **Legacy** to earn Heavenly Chips and unlock permanent Prestige Upgrades across runs.
- **Synthesized Wood-Drum Audio**: Web Audio API hollow "TUNG!" drum clicks, chimes, and fanfares with zero external audio downloads.
- **Save & Offline Progress**: Automatic `localStorage` saving, Base64 Export/Import, and offline earnings.
